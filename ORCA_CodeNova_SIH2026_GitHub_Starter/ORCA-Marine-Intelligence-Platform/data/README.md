# Data directory

This directory is reserved for future data documentation and approved sample fixtures.

## Data handling rules

- Do not commit API keys, credentials, private user information or restricted datasets.
- Confirm the source licence and redistribution rights before adding any dataset.
- Label synthetic/demo data clearly; never present it as live marine observations.
- Preserve units, coordinate reference systems, timestamps and provider attribution.
- Keep large raw datasets outside Git unless the team has a clear, approved reason to version them.
