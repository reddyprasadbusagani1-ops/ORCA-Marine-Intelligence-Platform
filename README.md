# ORCA-Marine-Intelligence-Platform
ORCA is an Agentic AI-powered Marine Intelligence Platform integrating satellite, oceanographic, weather, and geospatial data to identify Potential Fishing Zones, assess marine safety, detect hazards, optimize routes, and deliver explainable recommendations through conversational AI. Developed by Team CodeNova for SIH 2026 (SIH26176 – ISRO).
